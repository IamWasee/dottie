# Icon sources

Vector sources for the app icon and the drawn icons in `leanring-buddy/Assets.xcassets`.

- `DottieCursor.svg`: Dottie's cursor (the `DottieCursorArrow` artwork) as a vector, 544 x 704.
- `AppIcon.svg`: the app icon, 1024 x 1024, built from `DottieCursor.svg`. Exported to every size in `AppIcon.appiconset`.
- `Unlock*.svg` and `NotchEffect*.svg`: the Home → Profile unlocks, 64 x 64, exported at 32pt (1x, 2x, 3x) into image sets of the same names.

To change one, edit the SVG and export PNGs at those sizes (any SVG renderer that supports blur filters, such as a browser).
